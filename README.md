## 📌 Project Overview

This is a C-based console application for managing student records using Data Structures and Algorithms (DSA) concepts. The project uses an array of structures and supports operations like adding, displaying, updating, deleting, sorting, and searching student records.

---

## 🧠 Key Concepts Demonstrated

- ✅ Structures
- ✅ Arrays
- ✅ Bubble Sort
- ✅ Linear Search and Binary Search
- ✅ Function Modularization
- ✅ Data Validation and Confirmation Logic

---

## 🎯 Features

| Feature                      | Description                                                         |
|-----------------------------|---------------------------------------------------------------------|
| ➕ Add Student               | Adds a student with unique roll number                              |
| 📄 Display Students         | Lists all students with their details                               |
| 🔍 Search (Linear)          | Searches student by roll number                                     |
| ✏️ Update Marks             | Updates marks after confirmation                                    |
| ❌ Delete Student           | Deletes a student after confirmation                                |
| 📊 Sort by Marks            | Sorts students using bubble sort in descending order of marks       |
| 🔎 Binary Search            | Efficient search after sorting by roll number                       |
